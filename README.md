# ESBN-iCub

System-identification experiments in which an Alemi-style efficient balanced spiking network learns the nonlinear rigid-body dynamics of an iCub arm and, in the final phase, the articulated hand.

## Scientific target

The robot teacher is

[
M(q)\ddot q + h(q, \dot q) = \tau.
]

To preserve the additive-input form used by Alemi et al., torque is itself generated by

[
\dot \tau = -\alpha \tau + \xi(t),
]

and the learned state is

[
x = [q, \dot q, \tau].
]

Therefore

[
\dot x =
\begin{bmatrix}
\dot q \\
M(q)^{-1}(\tau-h(q,\dot q)) \\
-\alpha\tau
\end{bmatrix}
+
\begin{bmatrix}
0 \\ 0 \\ \xi(t)
\end{bmatrix}.
]

The network receives only the additive command and teacher state during training; it is not given the mass matrix or inverse dynamics.

## Installation

Unit tests need only NumPy and pytest:

    pip install -e ".[test]"
    pytest -q tests/test_alemi_ebn.py tests/test_excitation.py

Robot tests install PyBullet and the pinned official iCub model package:

    pip install -e ".[test,robot]"
    pytest -q tests/test_icub_teacher.py tests/test_robot_experiment.py
